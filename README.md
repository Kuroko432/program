## Описание

Программа на C++ вычисляет **время передачи зашифрованного пакета данных** по каналу связи.

Пользователь вводит:
- **объём пакета данных** — в мегабайтах (МБ);
- **пропускную способность канала** — в килобитах в секунду (Кбит/с).

Программа переводит объём пакета из мегабайт в килобиты (1 МБ = 1024 × 8 = 8192 Кбит) и делит его на пропускную способность канала, получая **время передачи в секундах**.

Есть проверка входных данных: если объём отрицательный или пропускная способность канала равна нулю/отрицательна, выводится сообщение об ошибке.

## Сборка и запуск

\`\`\`bash
g++ task_variant.cpp -o task_variant -Wall -Wextra
./task_variant
\`\`\`
